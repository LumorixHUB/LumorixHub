# LUMORIX HUB

Oyunların merkezi. Yeni dünyaların başlangıcı.

## Hakkında
LUMORIX HUB, oyunları keşfetmek ve oyun kütüphanesini yönetmek için geliştirilen bir masaüstü uygulamasıdır.

## Teknolojiler
- TypeScript
- Vite
- Tauri 2
- Rust

## Oyunlar
- Lumora Wilds
- Lumorix City
- Bereketli Çiftlik
